E-Commerce Backend Test Console

This page talks directly to your gateway and helps you run the full microservice flow: create a user, log in, create catalog data, add items to cart, place an order, and inspect side effects.

Gateway UI: same origin, no CORS setup needed
State persists in browser storage
Built for your current Spring services

End-to-End Flow

Run the happy path in order or use the forms below for individual requests.

1
Create user Registers a test user in `user-service`.
2
Login user Stores the JWT token and user id for authenticated requests.
3
Create product Adds a product in `product-service` through the gateway.
4
Create inventory Creates stock for the product in `inventory-service`.
5
Add product to cart Triggers cart, product, and inventory reservation logic.
6
Create order Runs payment, stock deduction, cart checkout, and notifications.
7
Verify side effects Checks payment, notifications, inventory, and order state.
